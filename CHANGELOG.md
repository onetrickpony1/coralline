# Changelog

## Unreleased

### Features
- **First version.** Open a saved JASP file and copy any of its tables as an APA 7 table, with what only you can add highlighted.
- **A new look.** Liquid glass panels over soft colour, with light, dark and pink themes (or follow the system), and a new icon: the psychology psi with the J of JASP.
- **Fast on any computer.** The background is painted once and only floating menus blur what is behind them, so scrolling and theme changes stay smooth. Jumping to a table scrolls with an eased animation. **Reduce effects** in the menu turns off transparency and animation for slower computers, and comes on by itself when the system asks for less motion or transparency.
- **The icon matches the theme**: blue in light, dark grey in dark, pink in pink. Choose one in the menu to keep it. On Linux the app installs its own desktop entry, so Wayland taskbars show the icon instead of a generic one.
- **Reloads when JASP saves**, keeping your place. The sync symbol next to the file name, a clear glass bead, spins when the tables update; click it to reload now. Also: search and filter tables (to copy / copied), a count of copied tables, recent files, copy all tables, copy as plain text, number the first table, jump to each highlight, hide highlights in the preview, preview size, and keyboard shortcuts (press F1).
- **Every column has a heading, as APA 7 asks.** Pairs and paths ("Revise – Exam", "Framing → Justification") become one first column headed "Variables" or "Path", and empty headings are named after what the column holds (Predictor, Source, Model, Test). "Variable" is used only when the column lists the analysis's own variables; anything unsure says "[Add heading]".
- **More columns are named for you.** Post hoc comparisons become one "Comparison" column ("Beer – Wine"), and confusion matrices, hypotheses, factors, effects and meta-analysis parameters get their headings. Across JASP's examples, columns asking for a heading went from 106 to 54; the rest depend on the field (audit, machine learning) and stay highlighted.
- **Sample size from the data.** When an analysis's tables don't report *N* (correlations, reliability), it is counted from the data saved in the file: rows that pass the filter and have every variable the analysis uses. Frequency data adds up its counts, and when missing values give each test its own *N* the note gives the range.
- **Sample size for more analyses.** Frequency data (contingency tables, multinomial and log-linear tests) adds up its counts, using the real values when JASP stores them as codes. SEM models written as syntax find their variables. Full-information maximum likelihood counts every row with any value. Regression and GLM weights no longer stop the count.
- **A range when each test has its own N.** With missing values handled per variable or pair (t-tests, paired tests, pairwise correlations), the note says "*N*s range from 8 to 9 because of missing values" instead of asking you.
- **Sample size the way APA's sample tables do it.** Meta-analyses say "Number of studies = 18, total *N* = 2,899" (and the number of effects for multilevel models) instead of a wrong *N*. Tables that show their own sample, tables without numbers and audit settings no longer ask for one. Binomial summary data gets *N* = successes + failures, and JAGS models use their own *n*.
- **See exactly what was changed.** A **What changed** button on each table (or <kbd>W</kbd>) lists every rule that changed something, why APA 7 asks for it, and each value before and after, compared with the table as JASP shows it: decimals, leading zeros, abbreviations, italics, headings, notes, the title and the layout.
- **One-line install and updates.** Install with one line on Windows, Linux or macOS (see the README); run it again to update. On Linux it adds jAPAsp to the app menu.
- **The command is now `japasp`** (it was `japasp-tool`). Your theme, recent files and other settings move over by themselves the first time the new version starts. `japasp --version` prints the version.
- **Hide the table list.** The button at the left of the title bar (or <kbd>B</kbd>) folds the list of tables away so the tables use the whole window, and brings it back. The app remembers your choice.
- **Feedback and problems** in the menu opens a feedback form on GitHub with the app version and your system filled in. The menu and the bottom of the table list also say who made jAPAsp, with a link to the GitHub profile.
- **Only the tables for your report.** Assumption checks (normality, equal variances, collinearity diagnostics) start out of the numbering, and **Leave out** / **Put in report** on any table takes it out of the numbering and Copy all, or puts it back. The tables after it are renumbered.
- **Progress you can finish.** The ring counts the tables you've copied ("2 of 5 tables copied") instead of tables "ready", which the yellow parts kept at zero, and a copied table gets a tick in the list. The filters are All, To copy and Copied.
- **Help with the yellow parts.** Clicking a to-do under a table explains what to write, with an example from the table (a title naming its variables in the order the table shows them, up to four, with a prompt in place of short names like "drp"; what to do with such a name), jumps to that spot, and says how to remove the yellow in Word and Google Docs.
- **Notes on tables:** a line says when a table uses smaller type to fit the page, and when it has extras some courses don't use (VS-MPR, both Student and Welch rows) and how to turn them off in JASP.
- **Clearer wording.** "What changed" starts with "Your results are the same as in JASP"; copy messages say "Paste it, then finish the yellow part"; the README starts with what the app does for you and puts the double-click installer first.
- **Works in a narrow window.** Below 760 px the table list opens as a drawer (button or <kbd>B</kbd>), and the reload button stays visible.
- **Each file keeps its own first table number.** Search finds a table by its number ("table 1" no longer matches tables 10 and 11), and a clear button empties the search.
- **Know when you're finished.** After copying, the list and ring stay amber while yellow parts are left in your document, and the line under the ring names them ("Still to do in your document: 3 yellow parts (Tables 1, 2)"). A copied table with yellow parts keeps a small yellow dot beside its tick.
- **Copy again when a number changes.** Leaving a table out, changing the first number or new values from JASP marks the copied tables affected ("You copied this as Table 3. It's now Table 2"), in the list, on the card and in the message.
- **Copies are remembered** for each file, so the ticks are still there the next day.
- **Fewer yellow dots.** Nearly every table asks for a better title, so a table with only that to do gets a yellow ring; the filled, pulsing dot is kept for extra work (headings, names, a landscape page).
- **Same numbers, two tables.** When two descriptives tables repeat the same means and *SD*s (the t test's Group Descriptives and the Descriptives analysis), the second says so and offers to leave it out.
- **Plainer guidance.** Student and Welch rows, and VS-MPR, come with the exact JASP tick box and "your other numbers don't change"; left-out assumption checks say they're usually reported in a sentence; the start screen and Leave out say your JASP file is never changed.
- **The to-dos sit above the table**, so their help is on screen next to a tall table, and clicking one only scrolls if the spot is out of sight.
- **What changed** lists one line per rule, opened with a click, has a **Hide changes** button at the end, and says when a value was only highlighted for you to explain.
- **Tidier cards and title bar.** **Copy APA table** is the one main button; Copy as plain text and Leave out are in a small menu on each card. The theme choice moved into the menu, with names. With a file open, the menu also has Open recent and Close file. In a narrow window the title bar stays on one row and keeps the file name.
- **Progress in the title bar** when the table list is hidden; click it to bring the list back.
- **The dark theme's main buttons are a muted blue**, so they read as the main action on graphite.
- **The list shortens titles that start the same** ("… Charisma" under Post Hoc Comparisons) and wraps to two lines; group counts are the tables in your report.
- **Search finds variables and labels** inside tables ("adverts", "Welch").
- **Single-key shortcuts can be turned off** in the menu, for screen readers. Tab leaves the menu closed behind it, and <kbd>W</kbd> moves the focus into What changed.
- **The reload button shows whether the file is watched**: a green dot when JASP's saves reload the tables, an empty one when not.
- In the To copy view, a copied table leaves the list after a moment. Messages appear in the bottom right, away from what you're reading.
- **A Mac installer download** (`jAPAsp-install-mac.zip`) next to the Windows one.

### Fixes
- **Levene's test in ANOVA** ("Test for Equality of Variances") and the quality-control normality summary now start out of the report like other assumption checks.
- **Group sizes are *n*** in descriptives by group, as APA asks; *N* stays for the whole sample.
- **No space before a full stop after an italic word** in notes ("group *Treat*." instead of "group *Treat* .").
- **Settings for the files you use most are kept**: the 50 remembered are now the 50 most recently used, not the first 50 opened.
- <kbd>Esc</kbd> in the keyboard shortcuts window no longer clears the search; Number the first table can't be changed with no file open; the table list header no longer jumps while it folds away.
- **The copy buttons are always on screen.** A wide table made the page wider than the window and pushed **Copy APA table** off the right edge, even on a 1366 px laptop screen. Long notes now wrap at the page width in the preview, as they do when pasted.
- **A failed reload no longer says the tables were updated.** If the file couldn't be read (JASP still writing it), the app said "Tables updated" and kept the old numbers. It now says the tables are from before, and tries again at the next check.
- **Copied ticks survive a reload** and belong to the right tables.
- **Student's whole *df* shows without decimals** ("42") next to Welch's ("37.86"), instead of "42.00".
- **Tables JASP couldn't compute, or left empty, are shown as such** instead of disappearing and shifting the numbers.
- **Analyses with the same name are numbered** ("Linear Regression (2)"); the list shows the tidied table titles, with the full title on hover.
- **Files with only plots** say so, instead of "no results tables".
- **No match** says which filter is on and offers Clear search and Show all tables.
- **The shortcuts list opens with <kbd>F1</kbd>**, which works on any keyboard; <kbd>?</kbd> needed Shift, and / alone starts a search.
- Caps Lock no longer turns off <kbd>C</kbd>, and shortcuts don't fire behind the keyboard shortcuts window.
- The "!" on the reload button, which looked like an error, is gone; its tooltip says when the file isn't being watched and where to turn that on.
- Easier to read and use with a keyboard or screen reader: grey text has at least 4.5:1 contrast, the list's dots and ticks have text for screen readers, arrow keys move between theme, filter and icon choices, and the menu is announced as a set of options.
- The start screen's hint is centred, Reduce effects makes the menu fully solid, and copy messages are solid and say "the yellow part" instead of "the 1 highlight".
- **App search shows the chosen icon straight away (KDE).** After you picked another app icon colour, KDE's app search and menu kept the old icon for up to a minute; now they update at once.
- **"Match theme" fits its button.** In the menu's App icon choice, the "Match theme" label ran past the edges of its highlighted box; the button now takes the width its text needs.
- **One yellow.** The to-do bubbles under each table are the same glass as the other buttons, with the sidebar's pulsing yellow dot instead of a yellow fill; the flash when jumping to a highlight uses that yellow too. Highlights inside the tables stay bright yellow, as they paste.
- **Smooth status dots.** The dots next to each table in the sidebar had jagged, pixelated edges; they are now drawn smooth, and the yellow ones (still to do) pulse gently. Reduce effects stops the pulse.
- **Correlation tables with confidence intervals follow APA.** Each interval goes in square brackets under its *r* (".24 [−.10, .54]") instead of separate Lower and Upper rows, with a note saying so. Correlations show two decimals (a third only for values under .01), the copy uses true minus signs, and JASP's significance note becomes "*p < .05. **p < .01. ***p < .001."
- **Smooth scrolling on Linux.** A workaround for blank windows on older NVIDIA drivers made WebKit copy every frame through memory, and it was on for everyone. It now applies only on Wayland with NVIDIA drivers older than 545. Setting `WEBKIT_DISABLE_DMABUF_RENDERER` yourself still wins.
- **Files with very large numbers open.** A meta-analysis file in JASP's Data Library didn't open ("number out of range"); now it does.
- **Missing values are counted the way JASP counts them.** The sample size now leaves out values stored as "nan", values matching the file's empty-value list ("." and others), and missing levels in nominal columns. Wide-format measurement data gets no count from rows.
- **Checked against all of JASP's examples.** Every table in JASP's 124 Data Library files was run through the copier. Fixes from that: pairs written with any JASP symbol become one column, empty columns are removed, "NaN" becomes a dash, and small values follow the decimals instead of showing as 8.72×10⁻⁴.
- Audit files and quality-control measurement data no longer take *N* from the data's rows: those rows are a population or single measurements, and the tables give the real sample.
